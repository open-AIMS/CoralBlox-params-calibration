# Data Sources

The data used in the calibration is created/modified by the
[Data-Gen-Calibration](https://github.com/DanTanAtAims/Data-Gen-Calibration) repository and
the [Reef-Monitoring](https://github.com/DanTanAtAims/Reef-Monitoring) web scraper (private
repository).

## Domains

- `rme_domain`

The reefmod engine v1.0.28 is used for historic DHWs. Available on the RRAP M&DS Data Store.

## Geospatial

- `canonical_gpkg`

Canonical geopackage generated by [Canonical Reefs](https://github.com/gbrrestoration/canonical-reefs).

- 'ltmp_shp'

Long Term Monitoring Program shape files defining the northern, central and southern LTMP
regions.

- `classification_path`

Location classification generated by [Data-Gen-Calibration](https://github.com/DanTanAtAims/Data-Gen-Calibration).
See the documentation of the outputs for more [information](https://github.com/DanTanAtAims/Data-Gen-Calibration/blob/main/docs/output_data.md)

## Observations

- LTMP Reef level manta tow data

This is loaded from the path in the configuration file called `ltmp_reef_data` under the
`Observations` sections.

This data is derived from [AIMS data](https://apps.aims.gov.au/metadata/view/5bb9a340-4ade-11dc-8f56-00008a07204e)
and modified in the [Data-Gen-Calibration](https://github.com/DanTanAtAims/Data-Gen-Calibration)
repository. There may be multiple LTMP observations per reef polygon, and LTMP observations
with no corresponding reef polygon.

- LTMP Manta Tow data for Location Classification

This is loaded from the path in the configuration file called `manta_tow_path` under the
`Observations` sections.

This data is derived from [AIMS data](https://apps.aims.gov.au/metadata/view/5bb9a340-4ade-11dc-8f56-00008a07204e)
where data is aggregated over location classes. The NetCDF contains the mean and standard
deviation of coral cover.

- LTMP Regional Coral Cover

This is loaded from the path in the configuration file called `ltmp_modelled_obs` under the
`Observations` sections.

The modelled regional coral cover for north, central and south regions including the upper
and lower confidence intervals.

- Coral Composition Data

This is loaded from the path in the configuration file called `composition_netcdf` under the
`Observations` sections.

The target coral composition for photogrammetry reefs. Generated by the [Reef-Monitoring](https://github.com/DanTanAtAims/Reef-Monitoring)
tool.
